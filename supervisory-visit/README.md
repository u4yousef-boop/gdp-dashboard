# استضافة الاستمارة على Cloudflare Workers

هذا المجلد يجمع الاستمارة وخدمة الذكاء الاصطناعي في مشروع واحد. الاتصال يتم من الخادم عبر Workers AI، ولا توضع مفاتيح API في المتصفح. كما أضيفت صفحة داخل تطبيق Streamlit باسم «استمارة الزيارة الإشرافية».

## نشر خدمة الاستمارة وWorkers AI

1. ثبّت Node.js وسجّل الدخول إلى Cloudflare.
2. افتح الطرفية داخل هذا المجلد.
3. شغّل `npx wrangler@latest login` واتبع صفحة التفويض الرسمية.
4. شغّل `npx wrangler@latest deploy`.
5. فعّل ربط Workers AI إذا طلب Cloudflare ذلك. سيظهر رابط الخدمة وينتهي بـ `workers.dev`.

## ربط صفحة Streamlit بالمساعد الذكي

بعد نشر تطبيق Streamlit وخدمة Cloudflare:

1. في أسرار تطبيق Streamlit، أضف:
   ```toml
   SUPERVISORY_AI_ENDPOINT = "https://YOUR-WORKER.workers.dev/api/ai"
   ```
2. في إعدادات Worker على Cloudflare، أضف متغير البيئة `ALLOWED_ORIGIN` واجعل قيمته أصل تطبيق Streamlit فقط، مثل `https://YOUR-APP.streamlit.app`، ثم أعد نشر Worker.
3. افتح صفحة «استمارة الزيارة الإشرافية» من قائمة صفحات تطبيق Streamlit.

إذا لم يُضبط رابط Worker، ستظل الاستمارة متاحة، وسيظهر تنبيه بأن المساعد الذكي يحتاج إلى إعداد.

## ملاحظات

- لا ترسل كلمة مرور الحساب أو مفاتيح API في المحادثة.
- فتح ملف HTML مباشرة عبر `file://` لا يتيح الاتصال بواجهة `/api/ai`.
- يوجد حد أولي يبلغ 20 طلبًا في الدقيقة لكل عنوان IP داخل ذاكرة Worker؛ اضبط حدودًا إضافية من لوحة Cloudflare قبل إتاحة الخدمة لعموم المستخدمين.
- Workers AI له حصة مجانية يومية منشورة؛ راجع التسعير الحالي قبل إتاحة الرابط للآخرين.
