# استضافة الاستمارة على Cloudflare Workers

هذا المجلد يجمع الاستمارة وخدمة الذكاء الاصطناعي في مشروع واحد. الاتصال يتم من الخادم عبر Workers AI، ولا توضع مفاتيح API في المتصفح.

## النشر

1. ثبّت Node.js على جهازك وسجّل الدخول في حساب Cloudflare من المتصفح.
2. افتح PowerShell في هذا المجلد.
3. شغّل `npx wrangler@latest login` واتبع صفحة التفويض الرسمية.
4. شغّل `npx wrangler@latest deploy`.
5. في أول نشر، وافق على تفعيل Workers AI إذا طلب Cloudflare ذلك. ستحصل على رابط ينتهي بـ `workers.dev`.
6. افتح الرابط الناتج بدل فتح ملف `public/index.html` مباشرة. عندها ستتصل أزرار المساعد بالمسار `/api/ai`.

## ملاحظات

- يحتاج النشر إلى حساب Cloudflare وتفويض Wrangler. لا ترسل كلمة مرور الحساب أو مفاتيح API في المحادثة.
- استخدم رابط الموقع المنشور. ملف HTML المفتوح عبر `file://` لا يستطيع الوصول إلى واجهة `/api/ai`.
- أُضيف حد أولي يبلغ 20 طلبًا في الدقيقة لكل عنوان IP داخل ذاكرة Worker. وللاستخدام العام، اضبط حدودًا إضافية من لوحة Cloudflare.
- Workers AI له حصة مجانية يومية منشورة؛ راجع التسعير الحالي قبل إتاحة الرابط للآخرين.
